## v1.0.1 · 2026-10-29 · 姓名识别加固

用户拿真实作业文件试跑后报了两类识别问题，一起修：

| 现象 | 根因 | 修法 |
|---|---|---|
| `朱雅新` 只识别出 `朱雅` | `新`、`正` 在 `BAD_NAME_CHARS` 里（当初防"新版/正本"误判），把常见名字字误杀 | 从黑名单移除 `新、正` |
| `巴桑嘉布` 识别成 `桑嘉布` 或直接失败 | `巴` 不是常见姓，`桑` 是，于是从名字中间截了一段 | ① 姓前面紧贴汉字时扣分，低分视为不可信；② 新增兜底：取紧挨学号的 2~5 个汉字；③ 低分且兜底无果就判"无法识别" |

连带修掉一个误判：`计算机组成原理-2034006-第4次作业` 原来会把"计算"当姓名，
现在正确报无法识别（课程名黑名单 + 弱匹配丢弃）。

验证：单元测试 12 → 17 个；`测试样例` 23 个真实文件仍全部"已符合"；安装包重打并重新走了一遍安装/卸载。

## v1.0.0 · 2026-10-29 · 安装包与注册表

用户要求"别人也能通过安装包安装"，并明确要一个**写注册表的程序**。

- 新增 `regtool.py`：复制程序、写 `HKCU` 注册表、建快捷方式、延迟自删除。
  选了 `HKCU` 而不是 `HKLM`：不需要管理员权限，普通学生电脑直接能装。
- 新增 `installer_main.py` / `installer_gui.py`：向导式安装，支持 `--silent` / `--uninstall`。
- 新增 `--open 文件夹`、`--uninstall` 两个应用参数：右键菜单用前者，卸载项用后者。
- 日志目录从"程序目录"改到 `%LOCALAPPDATA%\批量改名工具\改名日志`，避免卸载时被一并删掉。
- `build_release.ps1` 串起"主程序 → 载荷 → 单文件安装程序 → result"。

**踩到的坑（重要）**：在 `D:\DeepSeekHarness` 下生成的 exe 带"低完整性"标记，
双击会被拦，而且**进程写注册表直接 WinError 5**（同一份代码用 python 跑却正常）。
`icacls /setintegritylevel` 需要特权，改不了。最终方案：成品先复制到 `D:\_brt_staging`
再 `Move` 回工作区（同卷重命名保留安全描述符），标记就正常了 —— 这一步写进了打包脚本。

验证：静默安装 → 装好的命令行程序真实改名 → 日志落 `%LOCALAPPDATA%` → 卸载后
注册表键、开始菜单快捷方式、安装目录全部消失。

## v0.1 · 2026-10-29 · 初版

- 核心：学号（最长数字串）、作业（第N次/实验N 规范化）、姓名（常见姓 + 边界打分）、内容（剩余文字）。
- 模板：`{学号}{姓名}{作业}{内容}` + 任意字面量，按模板顺序组装。
- 安全：默认只预览、撞名跳过、两阶段改名、CSV 日志 + 撤销。
- 界面：tkinter，选文件夹、模板下拉、预览表、状态着色、选中行显示识别结果。
- 测试：需求里的三个例子 + 边界情况，12 个用例。

## 环境问题备忘

- `pyinstaller --onefile` 在当前沙箱跑不起来（临时目录受限）：测试时把 `TMP/TEMP` 指到可写目录，或改用 `--onedir` 验证。
- `tempfile.mkdtemp` 建的目录在沙箱里写不进：测试改用项目内 `_tmp\` + 普通 `mkdir`。
- `Start-Process` 启 GUI 会让工具调用挂住：用 `cmd /c start`。

# 批量改名工具

把格式各异的作业文件名，一次性统一成 `学号-姓名-第N次作业` 这种格式。
Windows 桌面程序，界面 + 命令行双入口，带安装包（自动写右键菜单、可正常卸载）。

| 改之前 | 改之后 |
|---|---|
| `徐阳-2034005-数据结构第4次作业-字符串的使用.docx` | `2034005-徐阳-第4次作业.docx` |
| `23530503杨丽第四次作业.pdf` | `23530503-杨丽-第4次作业.pdf` |
| `数据结构第1次作业-2025123509肖涵郡.docx` | `2025123509-肖涵郡-第1次作业.docx` |
| `2023567112532-巴桑嘉布-第1次实验报告.docx` | 已符合，跳过 |

## 功能

- **自动识别**：学号、姓名、作业信息从任意格式的文件名里拆出来，课程名不会被误认成姓名。
- **模板可配**：`{学号}` `{姓名}` `{作业}` `{内容}` 任意排列组合，分隔符随便写。
- **双入口**：tkinter 界面（选文件夹、实时预览、逐行核对识别结果）+ 完整命令行。
- **安全**：默认只预览；撞名跳过不覆盖；两阶段改名；每次操作写 CSV 日志，可撤销。
- **可分发**：单文件安装程序，写当前用户注册表（不需要管理员），自带卸载。

## 快速开始

### 用安装包（推荐）

1. 到 [Releases](../../releases) 下载 `批量改名工具-安装程序.exe`（或自己构建，见下）；
2. 双击安装，选安装位置（默认 `%LOCALAPPDATA%\Programs\批量改名工具`）；
3. 装完桌面有图标；任意文件夹右键 →「用批量改名工具整理」也能直接打开。

如果 Windows 弹「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」即可 —— 程序未做代码签名。

### 从源码运行

只需要 Python 3.9+（标准库，无第三方依赖）：

```powershell
python src\main.py                                   # 打开界面
python src\main.py --open "D:\作业\第4次"            # 打开界面并定位到该文件夹
python src\main.py -d "D:\作业\第4次" -t "{学号}-{姓名}-{作业}"   # 命令行预览
python -m unittest discover -s tests -v              # 跑测试
```

## 使用

### 界面

1. 选文件夹：点「浏览…」，或直接把路径粘贴进去按回车（带引号、结尾多反斜杠、粘贴文件路径都能认）；
2. 模板默认 `{学号}-{姓名}-{作业}`，下拉框有常用格式，改完按回车刷新；
3. 列表里绿色「待改名」、灰色「已符合」、红橙色有问题；**点某一行，底部会显示这行识别出的学号/姓名/作业**，逐个核对；
4. 「开始改名」二次确认后执行；改错了点「撤销上次改名」。

### 命令行

```powershell
改名工具-命令行.exe                              # 预览当前文件夹
改名工具-命令行.exe -d D:\作业 -r                # 含子文件夹
改名工具-命令行.exe -d D:\作业 --apply           # 真正执行
改名工具-命令行.exe --undo "…\改名日志-xxx.csv"  # 按日志还原
```

| 参数 | 说明 |
|---|---|
| `-d, --dir` | 要处理的文件夹，默认当前目录 |
| `-t, --template` | 目标模板，默认 `{学号}-{姓名}-{作业}` |
| `-r, --recursive` | 包含子文件夹 |
| `--apply` | 真正改名（不加就是预览） |
| `--undo 日志文件` | 按日志还原 |
| `--id-min-len` | 学号最少位数，默认 6 |

## 模板

| 占位符 | 含义 | 例子 |
|---|---|---|
| `{学号}` | 连续数字 | `2034005` |
| `{姓名}` | 姓名 | `徐阳` |
| `{作业}` | 作业信息，自动规范化 | `第4次作业`、`实验3` |
| `{内容}` | 剩下的文字 | `数据结构-字符串的使用` |

```
{学号}-{姓名}-{作业}        ->  2034005-徐阳-第4次作业
{学号}-{姓名}-第4次作业      ->  固定写成"第4次作业"，不管原来第几次
{姓名}_{学号}_{作业}        ->  徐阳_2034005_第4次作业
{学号}-{姓名}-{内容}        ->  2034005-徐阳-数据结构-字符串的使用
```

**输出顺序严格按模板里占位符的顺序**，不按原文件名的顺序重排。

## 识别规则

- **学号**：最长的连续数字串，默认 ≥6 位（`--id-min-len` 可调）。`第4次` 里的单个数字不算。
- **姓名**：常见姓（含欧阳、司马等复姓）+ 1~2 个名字字符，用前后边界与"后面是否跟第/次/作业"打分。
  没有常见姓的少数民族姓名（`巴桑嘉布`、`阿依古丽`）走兜底：取紧挨学号的 2~5 个汉字，
  并用课程词表排除 `数据结构`、`计算机组成原理`、`实验报告`；**两条路都不通就判无法识别，不瞎猜**。
- **作业**：`第4次作业`、`第四次作业`、`作业4`、`实验三` 统一成 `第N次作业` / `实验N`。
- **内容**：挖掉上述字段后剩下的文字。

识别不出的文件不参与改名，列表里标红写明原因。

## 开发与构建

```powershell
# 构建（Windows，需要 pip install pyinstaller）
pwsh -File scripts\build.ps1            # 绿色版 → dist\
pwsh -File scripts\build_release.ps1    # 安装包 → result\批量改名工具-安装程序.exe
```

安装包也可以静默安装/卸载（方便批处理）：

```powershell
result\批量改名工具-安装程序.exe --silent --dir "D:\Tools\批量改名工具"
result\批量改名工具-安装程序.exe --uninstall --silent
```

**发布**：`result\` 和 `dist\` 不进版本库（见 `.gitignore`），打 tag 后把 `result\` 里的安装包上传到 GitHub Releases。

### 安装程序写了哪些注册表

全部在 `HKEY_CURRENT_USER`，卸载时逐项清除：

| 位置 | 作用 |
|---|---|
| `Software\Classes\Directory\shell\BatchRenameTool` | 文件夹右键菜单 |
| `Software\Classes\Directory\Background\shell\BatchRenameTool` | 文件夹空白处右键菜单 |
| `Software\Microsoft\Windows\CurrentVersion\Uninstall\BatchRenameTool` | 「应用和功能」卸载项 |
| `Software\BatchRenameTool` | 安装路径、版本、安装日期 |

## 常见问题

**双击 exe 被 Windows 拦下**：未签名程序的常规提示，点「更多信息 → 仍要运行」。
实在不行用 `scripts\启动界面.bat` 直接跑源码。

**安装时提示「无法写入注册表」**：安装包被放进了带「低完整性」标记的目录，
复制到桌面再运行即可（`scripts\build_release.ps1` 里有自动处理）。

**某个文件没被改**：看它的状态原因，最常见是学号不足 6 位或姓氏不在表里。
把姓加进 `src/namer/core.py` 的 `SURNAMES_SINGLE` 即可。

## 已知限制

- 姓名识别靠常见姓 + 边界打分，极生僻的姓可能认不出（认不出会跳过，不会改错）。
- 一个文件名里有多个长数字串时，只取最长的一个当学号。
- 中文数字支持 1~99。
- 只改文件名主干，扩展名原样保留；`.tar.gz` 会当成扩展名 `.gz`。
- 只处理文件，不改文件夹名。

# 批量改名工具 · 使用说明

版本 1.0.0 ｜ 适用于 Windows 10 / 11（64 位）

把乱七八糟的作业文件名，一次性统一成 `学号-姓名-第N次作业` 这种格式。既能在界面上点，也能在命令行里跑。

例子：

| 改之前 | 改之后 |
|---|---|
| 徐阳-2034005-数据结构第4次作业-字符串的使用.docx | 2034005-徐阳-第4次作业.docx |
| 23530503杨丽第四次作业.pdf | 23530503-杨丽-第4次作业.pdf |
| 数据结构第1次作业-2025123509肖涵郡.docx | 2025123509-肖涵郡-第1次作业.docx |

---

## 一、安装

1. 双击 **`批量改名工具-安装程序.exe`**。
2. 如果 Windows 弹「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。
   程序是个人作品、没有购买数字签名，这个提示只表示"系统不认识这个发布者"。
3. 安装位置默认是 `C:\Users\<你的账户>\AppData\Local\Programs\批量改名工具`，
   装在这里**不需要管理员权限**。想装别处也可以点「浏览…」。
4. 两个勾选项：
   - **创建桌面快捷方式**：在桌面放一个「批量改名工具」图标。
   - **添加右键菜单**：在任意文件夹上右键，多出「用批量改名工具整理」，
     选中后直接打开程序并定位到那个文件夹，省得再选一次。
5. 点「开始安装」，几秒完成，可以选择立即打开。

安装程序做了三件事：把程序文件复制到安装目录、创建快捷方式、写入注册表。
注册表项全部在当前用户下（`HKEY_CURRENT_USER`），不装服务、不改系统设置：

| 注册表位置 | 作用 |
|---|---|
| `Software\Classes\Directory\shell\BatchRenameTool` | 文件夹右键菜单 |
| `Software\Classes\Directory\Background\shell\BatchRenameTool` | 文件夹空白处右键菜单 |
| `Software\Microsoft\Windows\CurrentVersion\Uninstall\BatchRenameTool` | 「设置 → 应用」里的卸载信息 |
| `Software\BatchRenameTool` | 安装路径、版本、安装日期 |

## 二、日常使用

### 方式一：界面

双击桌面图标，或者在文件夹上右键选「用批量改名工具整理」。

1. **选文件夹**：点「浏览…」，或者直接把路径粘贴到「文件夹」框里按回车
   （带引号、结尾多个反斜杠、甚至粘的是某个文件的路径，都能认）。
2. **确认模板**：默认 `{学号}-{姓名}-{作业}`，下拉框里有几种常用格式。
3. **看预览**：列表里绿色「待改名」、灰色「已符合」、红橙色是有问题的。
   **点任意一行，窗口最下方会显示这行识别出的学号、姓名、作业**——逐个核对一下最靠谱。
4. **开始改名**：弹窗确认后执行。改完提示日志位置。
5. **改错了**：点「撤销上次改名」，按日志把文件名原样还原。

### 方式二：命令行

安装目录下的 `改名工具-命令行\改名工具-命令行.exe`：

```powershell
# 预览当前文件夹（默认只预览，不动文件）
改名工具-命令行.exe

# 指定文件夹和模板
改名工具-命令行.exe -d D:\作业\第4次 -t "{学号}-{姓名}-{作业}"

# 确认无误后真正执行
改名工具-命令行.exe -d D:\作业\第4次 --apply

# 连子文件夹一起处理
改名工具-命令行.exe -d D:\作业 -r --apply

# 按日志撤销
改名工具-命令行.exe --undo "路径\改名日志-20261029-213000.csv"
```

| 参数 | 说明 |
|---|---|
| `-d, --dir` | 要处理的文件夹，默认当前目录 |
| `-t, --template` | 目标模板 |
| `-r, --recursive` | 包含子文件夹 |
| `--apply` | 真正改名（不加就只是预览） |
| `--undo 日志文件` | 按日志还原 |
| `--id-min-len N` | 学号最少几位，默认 6 |

## 三、模板怎么写

模板 = 固定文字 + 占位符，分隔符用 `-`、`_`、空格都行。

| 占位符 | 含义 | 例子 |
|---|---|---|
| `{学号}` | 连续数字 | `2034005` |
| `{姓名}` | 姓名 | `徐阳` |
| `{作业}` | 作业信息，自动规范化 | `第4次作业`、`实验3` |
| `{内容}` | 除以上之外剩下的文字 | `数据结构-字符串的使用` |

常见写法：

```
{学号}-{姓名}-{作业}        ->  2034005-徐阳-第4次作业
{学号}-{姓名}-第4次作业      ->  固定写成"第4次作业"（不管原来第几次）
{姓名}_{学号}_{作业}        ->  徐阳_2034005_第4次作业
{学号}-{姓名}-{内容}        ->  2034005-徐阳-数据结构-字符串的使用
```

`{作业}` 跟着原文件走（收到第 5 次的就写第 5 次），适合一次处理好几批；
把 `第4次作业` 写成固定文字，则一律改成第 4 次，适合一批一批处理。

## 四、程序如何识别

- **学号**：最长的连续数字串，默认至少 6 位。`第4次` 里的单个数字不会被当成学号。
- **姓名**：以常见姓（含欧阳、司马等复姓）开头，取 1~3 个字，靠"前后是不是分隔符、
  后面跟的是不是第/次/作业"来判断边界。碰不到常见姓的（藏族、维吾尔族等姓名，如
  "巴桑嘉布""阿依古丽"），会退一步取紧挨学号的那段 2~5 个汉字当姓名。
  课程名、作业名不会被误当姓名（如"数据结构""实验报告"会被排除）。
- **作业**：`第4次作业`、`第四次作业`、`作业4`、`实验三` 都统一成 `第N次作业` / `实验N`。
- **内容**：去掉学号、姓名、作业后剩下的文字。

**认不出来的文件不会动**，会标红写明原因（比如"文件名里找不到学号"），改名时自动跳过。
所以可以放心一次性框选整个文件夹。

## 五、安全设计

1. 默认只预览；界面必须点「开始改名」并二次确认，命令行必须加 `--apply`。
2. 两个文件会改成同一个名字、或目标名已被占用时，标「重名冲突」跳过，**绝不覆盖**。
3. 已符合格式的不改，无法识别的不改。
4. 两阶段改名，避免"A 要改成 B 的名字、B 又要改成 C"时互相卡死。
5. 每次改名写一份 CSV 日志，随时可撤销。
   日志位置：`C:\Users\<你的账户>\AppData\Local\批量改名工具\改名日志\`
   （卸载程序也不会删日志）。
6. 只改文件名，不动文件夹、不动文件内容。

## 六、卸载

任选一种：

1. **设置 → 应用 → 已安装的应用 → 批量改名工具 → 卸载**；
2. 重新打开安装程序，点「卸载」；
3. 命令行：`"安装目录\改名工具\改名工具.exe" --uninstall`

会删除：程序文件、开始菜单和桌面快捷方式、上表所有注册表项。改名日志保留。

## 七、常见问题

**Q：双击安装程序没反应 / 被 Windows 拦？**
先看有没有「Windows 已保护你的电脑」窗口（可能在任务栏闪烁），点「更多信息 → 仍要运行」。
少数安全软件会把未签名的 Python 打包程序误报，可以加入信任或白名单。

**Q：右键菜单没出现？**
资源管理器缓存，注销/重启一次，或任务管理器里重启「Windows 资源管理器」。
确认安装时勾了「添加右键菜单」。

**Q：某个文件没被改名？**
看它那一行的状态和原因。最常见是"文件名里找不到学号"（数字少于 6 位）或"找不到姓名"（生僻姓）。
可以把学号最少位数调小一点，或者手动改这个文件。

**Q：两个同学的作业评分一样，会变成同名吗？**
会检测到并标「重名冲突」，两个都不改，不会互相覆盖。

**Q：能改文件夹名字吗？**
不能，只处理文件。目录只用于"包含子文件夹"选项。

**Q：日志在哪？怎么恢复很久以前的改名？**
`C:\Users\<你的账户>\AppData\Local\批量改名工具\改名日志\`，文件名带时间戳。
用命令行 `--undo "日志路径"` 即可还原。

## 八、其他

- 技术：Python 3.13 + tkinter，PyInstaller 打包；核心识别逻辑与界面分离，源码结构见项目 README。
- 已知限制：姓名识别基于常见姓氏表和边界打分，极其生僻的姓可能认不出（认不出会跳过，不会改错名字）；
  一个文件名里有多个长数字串时，只取最长的一个当学号。

# 核心要求
开发一个简单的改名软件，用于实现批量修改文件名为指定格式
# 预期效果
1. 一个执行程序，有简介UI（脱离web的简单界面）界面，同时支持命令行操作，ui界面可以选择文件夹为工作目录，命令行则默认操作本文件夹目录。
2. 可以修改指定文件名格式（如包含几部分，以什么分隔）
3. 修改对象文件名格式任意，但包含指定文件名格式所需要部分。这里涉及到自动识别姓名、内容等。
# 例子
预设：学号-姓名-第4次作业
修改文件：徐阳-2034005-数据结构第4次作业-字符串的使用、23530503杨丽第四次作业、23443433-李虎-第4次作业
修改结果：徐阳-2034005-第4次作业、杨丽-23530503-第4次作业、23443433-李虎-第4次作业
